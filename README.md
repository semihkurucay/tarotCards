# 🔮 Tarot

**Tarot**, bilgisayarınızda tarot kartlarını kolayca açmanızı sağlayan bir uygulamadır. Kartlar rastgele dağıtılır ve tarotun mistik bilinmezliğini dijital ortamda yaşamanızı sağlar.

## ✨ Özellikler

- 🃏 Rastgele tarot kartı dağıtımı ile gerçekçi deneyim  
- 🎨 Arka plan rengini kişiselleştirme imkanı  
- 🖨️ Seçilen kartların belirlediğiniz sırada çıktı alma özelliği
